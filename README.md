## 🛠 Ключевые архитектурные и технические решения

### 1. Интерактивный хаб «Кейсы.html»
* **26 структурированных проектов:** разбиты по 5 направлениям (ИИ, Маркетинг и аналитика, Ребрендинг, Сайты, PR).
* **Модуль искусственного интеллекта:** в карточке *«Примеры работ по искусственному интеллекту»* размещены 3 прямые кнопки быстрого перехода на дашборды hh.ru, ИТ-компании и стоматологии.
* **Подсветка ссылок на дашборды:** плавное свечение проходит по кругу hh.ru → ИТ-компания → Стоматология, по 1,5 секунды на ссылку (полный цикл — 4,5 секунды). Наведение и фокус клавиатуры отключают цикл на время взаимодействия; `prefers-reduced-motion` отключает анимацию. Реализация на CSS без таймеров JavaScript; `index.html` и `cases.html` содержат ту же версию хаба, что и `Кейсы.html`.
* **Фильтры без навязчивой анимации:** удалены все мерцания, чип «Все (26)» выполнен в спокойном нейтральном стиле без неоновой подсветки.
* **Быстрый поиск и фильтрация:** полнотекстовая фильтрация на клиенте с подсчётом активных карточек в реальном времени.

### 2. HR-аналитический срез «hh.ru.html»
* **Объём данных:** 201 вакансия с детальной разбивкой по трекам (CMO / Маркетолог).
* **Конфиденциальность:** удалены внутренние служебные даты, отладочные комментарии скоринга и названия внутренних нейросетей-агентов.
* **Интерактивность:** мгновенная фильтрация по грейдам, стеку и зарплатным вилкам.

### 3. Маркетинговый срез «ИТ-компания.html»
* **Полнота аналитики:** 3 части отчёта, 7 интерактивных графиков (ECharts), 4 KPI-карточки, когортный анализ и 142 рекламные кампании.
* **Анонимизация:** 0 упоминаний исходных брендов, зашифрованные масштабированные показатели (ROMI = +439%).

### 4. Аналитический срез «Стоматологическая клиника.html»
* **Тема оформления:** по умолчанию при открытии страницы **всегда загружается светлая тема** (`data-theme="light"` в теге `<html>` без темного мерцания при загрузке).
* **Города присутствия:** Казань и Екатеринбург (исходные локации полностью заменены).
* **Коэффициентное шифрование:** все финансовые и количественные метрики надёжно защищены масштабирующими коэффициентами.

## 🛠 Сопровождение и публикация

* **Источник опубликованного хаба:** `Кейсы.html` в этом репозитории. После правки его содержимое копируется без изменений в `index.html` и `cases.html`; все три файла должны совпадать.
* **Размещение файлов:** HTML-страницы остаются в корне, поскольку GitHub Pages публикует корень ветки `main`, а их имена задают действующие URL и совместимые алиасы. Переименование с числовыми префиксами изменит опубликованные адреса. `README.md`, `.gitignore` и `.nojekyll` также имеют стандартные технические имена. Дополнительная документация размещается в `docs/` с нумерацией файлов.
* **Изменения каталога:** количество материалов обновляется в заголовке, навигации, фильтрах, итоговой сводке и `applyFilter()`. Текущий состав: 1 ИИ-проект, 10 кейсов, 1 ребрендинг, 9 сайтов и 5 публикаций — всего 26 карточек.
* **Проверка перед публикацией:** `git diff --check`, совпадение трёх HTML-файлов, счётчики поиска и фильтров; при изменении подсветки — порядок свечения, наведение, фокус клавиатуры, уменьшение движения и две темы оформления.
* **Публикация:** коммит и `git push origin main` запускают сборку GitHub Pages. Готовность проверяется по статусу `built` и содержимому опубликованной страницы.
* **Временные материалы:** скрипты разовых проверок, скриншоты и кэши не включаются в репозиторий; после завершения проверки удаляются из рабочей папки.

Описание сохранённых изменений и результатов проверки: [docs/01_Изменения_2026-10-09.md](docs/01_Изменения_2026-10-09.md).
