# 📥 00-Входящие — временные файлы от владельца

**Правило:** сюда владелец складывает файлы для изучения или выполнения задач — **вместо «скрепки» в чате**.

- 🟢 **Можно класть всё:** документы, выгрузки, скриншоты, архивы, черновики, **доступы и пароли**.
- 🟡 **Файлы здесь живут временно** — только до команды **«сохрани»**.
- 🔴 **В GitHub из этой папки не уходит ничего**, кроме этого README (см. `.gitignore` рядом). Проверено: блокируются и обычные файлы, и dot-файлы (`.env`, ключи), и вложенные подпапки. Пароли сюда класть можно — в git они не попадут никогда.

## Когда проверять

🟢 Услышав **«изучи»**, **«доступы положил»**, **«положил во входящие»** или похожее — **сразу проверить `00-Входящие`** проекта, с которым идёт работа (если проект не назван — проверить все и доложить, где непусто), и взять файлы в работу без лишних вопросов.

## Что происходит по команде «сохрани»

1. 🟢 Агент разбирает содержимое: нужное (знания, файлы, документы) раскладывает по соответствующим тематическим папкам проекта.
2. 🔴 **Доступы и пароли** — только в штатные закрытые места проекта (`00-Ключи-и-доступы/`, `.env` — как принято здесь): 🔴 никогда в отслеживаемые файлы, никогда открытым текстом в README, скрипты и коммиты — только ссылка на путь к секрету.
3. 🔴 Очищается **только папка проекта, с которым работали** (остальные не трогаем) — остаются лишь этот README и `.gitignore`.
4. 🚀 Дальше — обычный протокол «сохрани»: документирование, коммиты, пуш.

📌 **Для будущих проектов:** каждый новый проект начинается с папки `00-Входящие` с этим же README.
